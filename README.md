# Raccolta Esercitazioni Scripting Linux 🐧

Benvenuto nella documentazione ufficiale delle mie esercitazioni di scripting in ambiente Bash. Questa cartella raccoglie una serie di script sviluppati per apprendere, testare e automatizzare operazioni di base e avanzate su Linux.

---

## Indice delle Esercitazioni

### 🔐 Gestione e Sicurezza
* **Accesso_Password**: Script incentrato sulla gestione dei controlli di sicurezza, verifica delle credenziali e inserimento sicuro di password tramite terminale.

### 🔀 Condizioni e Logica
* **Condition**, **Condizione_Di_Controllo**, **Condizione_Maggiore_Minore**, **Controllo_Condition**: Esercitazioni pratiche sull'uso delle strutture condizionali (`if`, `elif`, `else`) e degli operatori di confronto numerico e testuale.
* **Case_Experiment**: Test ed esempi di utilizzo della struttura di controllo multipla `case` per gestire più opzioni in modo pulito.

### 🔄 Cicli e Strutture Dati
* **Ciclo_Stampa_Valori**: Utilizzo dei cicli (`for`, `while`) per scorrere e stampare sequenze o elenchi di valori.
* **Primo_Script_Uso_Vettore**: Primo approccio alla gestione degli array (vettori) all'interno degli script Bash per memorizzare e manipolare più elementi.

### 📁 Gestione di File e Directory
* **Controllo_Directory**, **Controllo_File_Directory**: Script per verificare l'esistenza, i permessi e la natura di file e cartelle nel file system.
* **Creazione_Quattro_Cartelle**, **Programma_Creatori_Directory**, **Operazione_AggiungiFile**: Automazione per la creazione guidata di strutture di directory e l'aggiunta dinamica di file al loro interno.

### ⚙️ Struttura degli Script e Funzioni
* **Script_Base**: Un template di partenza minimale che racchiude la struttura standard di uno script Bash (shebang e intestazione).
* **Funzione_Base**: Introduzione alla modularità del codice tramite la creazione e la chiamata di funzioni personalizzate all'interno dello script.
* **Script_STOP**: Esempio di gestione dell'interruzione di un flusso di lavoro, gestione dei segnali o uscita condizionale anticipata dallo script.
